## 🚀 Featured Projects

- **[SBI Saathi AI](https://github.com/shubhamshubham66/SBI-Saathi-AI)**: Multilingual agentic banking assistant that helps users with UPI activation, product recommendations and government schemes. Built with Next.js, TypeScript, MongoDB and Gemini/OpenAI, with OTP login, JWT sessions and rate limiting. [Live](https://sbi-saathi-ai.vercel.app)
- **[Dayflow HRMS](https://github.com/shubhamshubham66/Dayflow_Human_Resource_MS)**: Full-stack HR management system with JWT auth, email verification and role-based dashboards. Built with React, Node.js, Express and MongoDB. [Live](https://dayflow-human-resource-ms.vercel.app)
- **[Cadet Connection Portal](https://github.com/shubhamshubham66/Cadet-Connection-Portal)**: Digital platform for the 15th Tripura Bn NCC with separate officer and cadet dashboards, attendance, ID cards and certificates. Built with HTML, CSS and JavaScript. [Live](https://cadet-connection-portal.vercel.app)
- **[AI Resume Analyzer](https://github.com/shubhamshubham66/Resume_Analyser)**: Analyzes PDF resumes and gives an ATS-style score, summary and improvement suggestions. Built with React, TypeScript and pdf.js. [Live](https://resume-analyser-logic7.vercel.app)
